# 娜緹夏天堂｜單機可玩原型

## 啟動
1. 安裝 Node.js 18 或更新版本。
2. 執行 `node server.cjs`，或雙擊 `start-local.bat`。
3. 開啟 http://127.0.0.1:8000（預設進入原版客戶端）；第一階段簡易原型仍可由 `/index.html` 開啟。

## 已實作
- 離線角色建立，資料儲存在本機瀏覽器。
- 斜角格狀測試地圖、玩家移動與尋路。
- 史萊姆生成、簡易追擊、攻擊、受傷、死亡。
- 經驗、升級、金幣掉落、拾取、治癒藥水。
- 手動攻擊與簡易 AUTO 狩獵。
- 方向鍵／WASD、點擊地面移動、點擊怪物攻擊。

## 重要限制
這是獨立可玩的第一階段原型，使用自繪佔位場景，尚未整合原版客戶端畫面、原版圖檔、全部地圖、完整怪物資料、技能公式、NPC／任務／商店及原伺服器規則。不能宣稱已完整轉換原版遊戲。後續仍須逐項移植。
所有工作只在 `offline/single-player-core` 分支，不修改 `main`。

## 原版客戶端離線接線（進行中）
- 已保存原版 `app.js`、`hud.js`、`l1map.js` 與 `style.css`，並提供原版遊戲資料快照。
- 已新增 `offline-engine.js`：模擬本機登入、角色建立／儲存、移動、史萊姆戰鬥、EXP、金幣拾取與紅色藥水回血。
- `app.js` 的 WebSocket 建立點已可切換至本機相容連線；離線登入會跳過 Google 與裝置驗證。
- 本機核心測試：在 `offline-client` 目錄執行 `node offline-engine.test.cjs` 和 `node offline-socket.test.cjs`。

**目前尚未完成：** 原版 HTML／完整 HUD DOM、原始地圖與圖集／SPR／UI 音效素材，以及完整服務端遊戲規則的本機化。現在的 `index.html` 仍是第一階段佔位原型，不能視為原版畫面已經接好。

## 原版相容畫面預覽
- 啟動本機伺服器後另開 `http://127.0.0.1:8000/original-client.html`。
- 根網址 `/` 與 `/original-client.html` 都進入原版客戶端離線入口；`/index.html` 保留第一階段獨立原型。
- `original-client.html` 已加入 Content Security Policy：只允許本機同源資料與素材，封鎖外部 API、Google 登入資源及遠端 WebSocket 連線。
- 離線版地圖模組已停用線上地圖索引重試；本機引擎會先讀取素材同步器下載的 `map/0` 原版通行遮罩，並以替代遮罩作後備。玩家與怪物移動都會驗證方向通行旗標。
- 目前已在隔離環境測試引擎協定與 JavaScript 語法；尚未在你的 Windows 瀏覽器實際驗證頁面視覺與全部按鈕行為。

- 出生點已校正為原版預載資料中的說話之島 `map=0, x=32593, y=32922`；本機 walk mask 使用地圖索引涵蓋的 512×512 座標範圍。此遮罩目前全可通行，尚未套用原版障礙物遮罩。


## 原版素材自動同步
- `start-local.bat` 會先執行根目錄的 `sync-original-assets.cjs`，把說話之島出生點周圍 3×3 個原版區塊、所需地磚圖集、選角圖、初始角色／史萊姆動畫和 HUD 圖示放進 `offline-client/assets`。
- 同步完成後，遊戲只讀取本機 `assets` 和 `map/0`；若原站某個檔案取不到，會回退本機替代繪圖與全可通行測試遮罩。
- 首次啟動需要網路下載素材；之後已存在的檔案會略過。要強制重抓可在專案根目錄執行 `node sync-original-assets.cjs --refresh`。
- 原版畫面入口：`http://127.0.0.1:8000/original-client.html`。

- 自動素材同步會依原版 L1S 索引選擇一般 SPR、75% 壓縮圖集與 50% 圖集；離線模式不會對缺失圖集／區塊持續重試。
